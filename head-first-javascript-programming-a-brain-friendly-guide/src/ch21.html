NGUYÊN LÝ CỐT LÕI

Đóng gói hành vi vào Object và quyền năng của this

TL;DR: Object không chỉ lưu dữ liệu mà còn chứa hàm (method), sử dụng từ khóa this để tự tham chiếu.

Khi xây dựng các hệ thống phức tạp như giỏ hàng tại Tiki hay hệ thống đặt xe của Grab, việc quản lý rời rạc các biến là thảm họa kiến trúc. Giải pháp là gom nhóm dữ liệu và hàm xử lý vào Object. Khi một hàm nằm bên trong object, nó được gọi là method. Để method truy cập được dữ liệu của chính object đó mà không bị phụ thuộc vào biến bên ngoài, ta bắt buộc phải dùng từ khóa this.

Hệ thống quản lý tài xế XanhSM định nghĩa mỗi xe là một Object chứa thông số định vị và phương thức updateLocation(). Bên trong phương thức, this.lat và this.lng cập nhật tọa độ GPS theo thời gian thực.

KIẾN TRÚC TRÌNH DUYỆT

Giao tiếp với trang web qua DOM (Document Object Model)

TL;DR: Trình duyệt chuyển đổi HTML thành cây Object gọi là DOM để JavaScript có thể đọc và ghi.

Mã JavaScript chạy độc lập với markup HTML cho đến khi xuất hiện DOM (Document Object Model). Khi trang web được tải, trình duyệt phân tích cú pháp HTML và dựng lên một cấu trúc cây các object. Object toàn cục document là điểm neo để truy xuất mọi thành phần giao diện thông qua các phương thức như getElementById.

Thực chiến tại Việt Nam

Khi Flash Sale trên Shopee đếm ngược từng giây, script JS liên tục gọi DOM để cập nhật text của thẻ HTML hiển thị thời gian còn lại mà không cần tải lại trang.

TỔNG KẾT CHƯƠNG

Thực hành & Kiểm tra kiến thức

Chương này lột tả bản chất của Object trong JavaScript không chỉ là tập hợp các cặp khóa-giá trị (key-value) tĩnh mà là các thực thể sống động chứa cả dữ liệu (properties) và hành vi (methods). Chúng ta học cách sử dụng từ khóa 'this' như một con trỏ ngữ cảnh để phương thức bên trong object có thể truy cập chính xác thuộc tính của nó mà không phụ thuộc vào biến toàn cục. Đồng thời, chương mở ra chương mới về DOM (Document Object Model) - cấu trúc cây dữ liệu đại diện cho trang HTML, cho phép mã nguồn JavaScript thao tác, thay đổi nội dung trang web động như cách các hệ thống lớn cập nhật giao diện thời gian thực.

Kiểm tra kiến thức cốt lõi

Câu 1: Từ khóa 'this' bên trong một method của object trỏ tới cái gì?

  1. Trỏ tới cửa sổ toàn cục (window)
  2. Trỏ tới chính object chứa method đó
  3. Trỏ tới một biến ngẫu nhiên
  4. Trỏ tới file HTML gốc

Trong ngữ cảnh của một method thuộc object, 'this' tham chiếu trực tiếp đến object gọi phương thức đó tại thời điểm thực thi.

Câu 2: Phương thức nào dùng để lấy một phần tử trên trang HTML thông qua định danh ID?

  1. document.getElementByClass
  2. document.querySelectorId
  3. document.getElementById
  4. document.getHtmlElement

document.getElementById() là phương thức chuẩn của DOM để tìm kiếm chính xác phần tử dựa trên thuộc tính id.
